# LeetCode Solutions

Repositório com resoluções de problemas do [LeetCode](https://leetcode.com/) em Python, organizado como parte dos meus estudos de estruturas de dados e algoritmos.

## 🎯 Objetivo

Praticar lógica de programação, algoritmos e estruturas de dados como preparação para processos seletivos técnicos e concursos públicos de TI, além de reforçar fundamentos usados no dia a dia como desenvolvedor backend.

## 🛠️ Linguagem utilizada

- **Python**

## 📁 Estrutura

Cada solução fica em um arquivo próprio, nomeado com o número e o título do problema no LeetCode, por exemplo:

```
217-Contains Duplicate.py
242-Valid Anagram.py
```

## ✅ Problemas resolvidos

| # | Problema | Dificuldade | Tópico |
|---|----------|-------------|--------|
| 217 | Contains Duplicate | Easy | Hash Set |
| 242 | Valid Anagram | Easy | Hash Map |

> Tabela atualizada manualmente conforme novos problemas são resolvidos.

## 📌 Convenções

- Soluções priorizam clareza e boas práticas (nomenclatura, complexidade de tempo/espaço comentada quando relevante).
- Cada arquivo pode conter comentários com a complexidade (Big O) e observações sobre a abordagem usada.

## 🚀 Como executar

```bash
python "nome-do-arquivo.py"
```
